# MCP競馬ナレッジResources（開発者向け）

`manifest.json` に記載したMarkdownをMCP Resourcesとして公開します。公開原稿は `spec/` 以下にあります。

- `procedure`: 予想の手順とレビュー方法。
- `knowledge`: 馬、レース構造、市場・馬券の判断知識。

本文の作成・採否・更新は開発者が行います。Resourceを追加・削除するときは、`manifest.json` と公開内容をそろえてください。

Resourceメタデータには `kind`、`status`、本文バイト列のSHA-256である `content_sha256`、根拠レースの終了日が分かる場合の `max_evidence_race_date` を返します。公開日時は設定・公開しません。使った本文はURIとハッシュで識別してください。

根拠資料の期間・標本数・タイミング・適用範囲は、manifestの `supporting_evidence_periods` に集約します。
資料は手順・条件比較・反例に関する注意点の根拠であり、本文全体の経験則や予測精度・損益の検証を意味しません。
標本数を各規則の適用回数や確率較正の標本数へ転用しません。支持期間を特定できない原則も含むため、
Resource全体の最大根拠日を確認済みとはせず `max_evidence_race_date` はnullを維持します。

ナレッジの適用時は公開・登録した時期から利用可否やリークを判断せず、実際の根拠内容と対象期間を確認してください。対象レースより後の根拠が確認できた場合は回顧的と明記し、根拠期間が未記載なら不明と記録します。

知識を採用する場合は適用条件、根拠、反証、限界とともにResourceへ記述します。

ResourcesはMCP起動時に本文とハッシュを固定して読み込みます。原稿を更新した後はMCP再起動で
本文・`resources/list` メタデータ・予想contextの参照を同時に読み直します。保存済みの本文と
ハッシュ、初期予想・順位・採点は新原稿で置き換えません。
