# 同梱する採用済みモデル

実測の採用ゲートを通過し、公開内容を開発者が確認した場合だけ、次の2ファイルをこのディレクトリに配置する。

- `prediction-model.json`: 数値の係数・木・学習時の補完値・較正値・特徴量契約・学習期間など。
- `prediction-model.manifest.json`: モデル版、SHA-256、バイト数。

この2ファイルをソースとともにGit管理し、wheelとsdistへ含める。
JSONがない場合は同梱線形係数を使う。読込時に整合性と採用状態を検証し、不正なファイルはエラーにする。

生データ、出馬表、レース別の予測・結果、評価レポート、DB接続情報、学習途中のファイルは配置しない。
これらはJSON形式であってもGit管理外の`archive/`にのみ保存する。
`python scripts/validate_model_bundle.py`で配布JSONの整合性を確認できる。
